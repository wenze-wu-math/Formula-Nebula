## 制作流程

### 完整时间线

| 阶段 | 时间投入 | 产出 |
|---|---|---|
| **前期准备** | 1-2 小时 | 脚本、演示环境、素材 |
| **录制** | 视频时长 × 2-3 倍 | 原始视频 + 音频 |
| **后期制作** | 视频时长 × 3-5 倍 | 成片 |
| **质量检查** | 30 分钟 - 1 小时 | 检查报告 |
| **发布** | 30 分钟 | 各平台上线 |

**示例**：制作一个 5 分钟视频
- 前期：1.5 小时
- 录制：10-15 分钟
- 后期：15-25 分钟
- 检查：30 分钟
- 发布：30 分钟
- **总计**：约 3-4 小时


```javascript

// 检查 GPU 加速

const fps = await new Promise(resolve => {
  let frames = 0;
  const start = performance.now();
  
  function count() {
    frames++;
    if (performance.now() - start < 1000) {
      requestAnimationFrame(count);
    } else {
      resolve(frames);
    }
  }
  
  requestAnimationFrame(count);
});

console.log('FPS:', fps);
// 期望：55-60 fps
```

### 录制流程

#### 第一遍：无声演练
1. 打开脚本，对照时间轴
2. 模拟每个操作，记录实际耗时
3. 标注需要调整的地方
4. 调整操作顺序（确保流畅）

#### 第二遍：有声演练
1. 读出讲解词（不录制）
2. 检查语速是否合适
3. 操作与讲解是否同步
4. 标注需要停顿的地方

#### 第三遍：正式录制
1. **开始录制前：**
   - 深呼吸 3 次（放松）
   - 关闭所有通知
   - 确认麦克风指示灯亮起
   - 默数 3-2-1 再开始操作

2. **录制中：**
   - 语速适中（每分钟 140-160 字）
   - 操作后停顿 0.5-1 秒
   - 出错立即停止，重录该段
   - 每 2-3 分钟存一个检查点

3. **录制后：**
   - 立即回放检查
   - 音频是否清晰
   - 操作是否流畅
   - 有无明显错误

### 分段录制技巧

每个视频按脚本的时间轴分段录制：

```bash
# 示例：01-getting-started.md

段落 1 (0:00-0:30): 开场.mp4
段落 2 (0:30-1:30): 界面概览.mp4
段落 3 (1:30-2:30): 基本交互.mp4
段落 4 (2:30-3:30): 搜索功能.mp4
段落 5 (3:30-4:30): 查看详情.mp4
段落 6 (4:30-5:00): 总结.mp4

# 优点：
- 每段独立，出错只重录一段
- 后期剪辑灵活
- 可并行制作（多人协作）
```

### 剪辑流程

#### 1. 导入素材

```
项目结构：
/01-getting-started
  /raw              # 原始录制
    - 开场.mp4
    - 界面概览.mp4
    - ...
  /audio            # 独立音频（如果分开录）
  /assets           # 素材
    - logo.png
    - intro.mp4     # 片头动画
    - outro.mp4     # 片尾动画
  /final            # 成片
```

#### 2. 粗剪

```
1. 按时间轴顺序拼接所有段落
2. 删除明显的错误（口误、长停顿）
3. 调整段落之间的衔接（0.5 秒淡入淡出）
4. 插入片头（5 秒）和片尾（5 秒）
5. 检查总时长（±30 秒以内）
```

#### 3. 音频处理

```
Audacity 流程：
1. 导入音频轨
2. 降噪
   - 选择静音段 → 效果 → 获取噪声配置
   - 全选 → 效果 → 降噪 → 应用
3. 均衡器
   - 低频 -3dB（减少闷响）
   - 高频 +2dB（提高清晰度）
4. 压缩器
   - 阈值: -20dB
   - 比率: 3:1
5. 限幅器
   - 硬限制: -3dB（防止削波）
6. 导出 WAV（替换原音轨）
```

#### 4. 细剪

```
逐帧检查：
☐ 鼠标移动平滑（无跳跃）
☐ 点击有明显停顿
☐ 画面与讲解同步（±0.5 秒）
☐ 关键操作有标注（箭头/圈圈）
☐ 转场自然（淡入淡出 0.5 秒）
☐ 无长时间静止画面（>3 秒）
```

#### 5. 标注与特效

```
标注类型：
1. 箭头
   - 指向关键按钮/区域
   - 颜色: 高亮黄 (#FFD700)
   - 持续: 1-2 秒

2. 圈圈
   - 圈出重要信息
   - 颜色: 半透明红 (#FF0000, 30%)
   - 持续: 1-2 秒

3. 放大
   - 放大小字/细节
   - 缩放: 1.5-2.0×
   - 持续: 2-3 秒

4. 文字标注
   - 字体: Roboto / 思源黑体
   - 大小: 36px (1080p)
   - 位置: 屏幕下方 1/3
   - 背景: 半透明黑 (#000000, 70%)
```

#### 6. 字幕制作

```
工具: Subtitle Edit

1. 导入视频
2. 自动识别语音（如果音频清晰）
3. 人工校对每一句
4. 调整时间码（与讲解对齐）
5. 双语字幕格式：
   ```
   00:00:05,500 --> 00:00:10,000
   欢迎来到公式诗云
   Welcome to Formula Nebula
   ```
6. 导出 SRT
7. 硬字幕烧录（推荐）或软字幕（可切换）
```

### 片头片尾

#### 片头 (5 秒)
```
结构：
0-1s: 黑屏淡入
1-3s: Logo 动画 + 项目名
3-4s: 视频标题淡入
4-5s: 标题保持，准备淡出

音效: 轻柔的 whoosh 音效（可选）
```

#### 片尾 (5 秒)
```
结构：
0-1s: 内容淡出
1-3s: 官网链接 + GitHub 链接
3-5s: Logo + "感谢观看"

下集预告（可选）:
- 缩略图 + "下一集：XXX"
- 点击跳转链接
```

### FFmpeg 批量压缩脚本

```bash
#!/bin/bash
# compress-videos.sh

INPUT_DIR="./raw"
OUTPUT_DIR="./compressed"

for file in "$INPUT_DIR"/*.mp4; do
  filename=$(basename "$file")
  
  ffmpeg -i "$file" \
    -c:v libx264 \
    -preset medium \
    -crf 23 \
    -c:a aac \
    -b:a 192k \
    -movflags +faststart \
    "$OUTPUT_DIR/$filename"
    
  echo "✓ $filename"
done
```

## 常见问题

### 问题：录制时帧率不稳定

**原因**：GPU 负载过高

**解决**：
1. 关闭后处理辉光（设置 → 显示层 → 后处理辉光）
2. 降低录制分辨率（先录 720p，后期放大到 1080p）
3. 使用 NVENC 硬件编码（OBS → 输出 → 编码器）

### 问题：音频有电流噪声

**原因**：电磁干扰或接地问题

**解决**：
1. 使用 USB 麦克风（避免 3.5mm 接口）
2. 麦克风远离电源线
3. Audacity 降噪（效果 → 降噪）

### 问题：鼠标点击不明显

**原因**：OBS 鼠标高亮未启用

**解决**：
```
OBS → 源 → 显示器采集 → 属性
☑ 捕获鼠标光标
☑ 高亮鼠标点击
  颜色: 黄色 (#FFD700)
  半径: 50px
```

### 问题：字幕与画面不同步

**原因**：导出时音画不同步

**解决**：
1. 检查原始视频是否同步（VLC 播放器逐帧检查）
2. 导出时选择"匹配源"而不是"自定义"
3. 使用硬字幕烧录（避免播放器解析差异）

### 问题：视频上传后画质下降

**原因**：平台二次压缩

**解决**：
1. 上传前提高比特率（1080p: 12 Mbps）
2. YouTube: 等待 HD 处理完成（上传后 1-2 小时）
3. Bilibili: 使用"超清"投稿选项
