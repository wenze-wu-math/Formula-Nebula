📈 Training Data Strategy
Phase 1: Bootstrap from Knowledge Graph
Use node.importance from the algebraic geometry knowledge graph as a proxy for difficulty. Quick to implement, provides baseline classification.
Expected Accuracy: ~75% Data Size: 120+ theorems
Phase 2: Expert Annotation
Manually label 50-100 representative proofs across all families (foundation, scheme, cohomology, etc.). Focus on edge cases and borderline examples.
Expected Accuracy: ~85% Effort: 5-10 hours
Phase 3: User Interaction Learning
Track actual reading time, revisit patterns, "mark as difficult" clicks, and completion rates. Continuously refine model based on real user behavior.
Expected Accuracy: ~90% Data Required: 1000+ user sessions
Phase 4: Fine-tuning with LLM
Use GPT-4 / Claude API for deep semantic analysis of proof text, concept dependencies, and mathematical reasoning. Extract latent features not captured by rule-based methods.
Expected Accuracy: ~95% Cost: ~$50-100 for full corpus
