✦ Proof Explorer Demo

Formula Nebula 交互式证明视图增强功能演示

🎯 核心功能
🎯
1. 证明步骤高亮
点击证明步骤可聚焦高亮，使用方向键快速导航，Enter 键展开/折叠步骤
💡
2. 定理悬浮提示
鼠标悬停在引用的定理链接上，自动显示定理陈述和摘要，无需跳转页面
🕸️
3. 依赖关系图
可视化展示证明步骤之间的依赖关系，以及证明依赖的前置定理
⚖️
4. 多证明对比
并排比较同一定理的不同证明方法，查看步骤数、难度和依赖差异
📊
5. 完整度指示器
显示证明的完整度评分，列出已包含和缺失的内容模块
📄
6. LaTeX 导出
一键导出证明为标准 LaTeX 文档，包含定理、证明步骤、参考文献
🔍
7. 定理使用搜索
查找哪些证明引用了当前定理，追踪定理在知识图谱中的使用情况
🌊
8. 证明流程动画
动态粒子流动画展示证明的逻辑推导流程，直观理解推理过程
⌨️ 键盘快捷键
↓ 下一步骤
↑ 上一步骤
Enter 展开/折叠
Esc 关闭证明页
💻 集成代码示例
// 1. 导入模块
import { createProofView } from './src/proofView.js'
import ProofExplorer from './src/proof-explorer.js'
import './src/proof-explorer.css'

// 2. 创建 proof view
const proofView = createProofView({
  graph: graphData,
  onNavigate: (id) => console.log('Navigated to:', id),
  onBack: () => console.log('Back clicked'),
  onGalaxy: () => console.log('Return to galaxy')
})

// 3. 初始化 Proof Explorer
const explorer = new ProofExplorer(proofView, graphData)

// 4. 打开证明并自动应用增强功能
proofView.mount()
proofView.open('valuation-ring')
explorer.enhanceProofView('valuation-ring')

// 5. 手动使用单个功能
// 高亮特定步骤
explorer.stepHighlighter.highlightSteps(['step-1', 'step-3'])

// 导出 LaTeX
explorer.latexExporter.downloadAsFile(
  nodeData.proof,
  'valuation-ring-proof.tex'
)

// 搜索定理使用情况
const usages = explorer.proofSearch.findUsages('valuation-ring')
console.log(`Used in ${usages.length} proofs`)

// 6. 监听事件
proofView.root.addEventListener('step:focus', (e) => {
  console.log('Step focused:', e.detail.stepId)
})

proofView.root.addEventListener('proof:switch', (e) => {
  console.log('Switched to proof:', e.detail.proof)
})
📝 使用说明
# 安装依赖
npm install katex three

# 在主项目中引入
import ProofExplorer from './src/proof-explorer.js'
import './src/proof-explorer.css'

# 在现有的 proofView 基础上初始化
const explorer = new ProofExplorer(proofView, graphData)

# 每次打开新证明时调用
proofView.root.addEventListener('proof:open', (e) => {
  explorer.enhanceProofView(e.detail.id)
})

# 清理资源
explorer.destroy()

📊 API 参考
// ProofExplorer 主类
class ProofExplorer {
  constructor(proofView, graph)
  enhanceProofView(nodeId)    // 自动应用所有增强
  destroy()                    // 清理资源
}

// ProofStepHighlighter
stepHighlighter.focusStep(element)
stepHighlighter.navigateStep('next' | 'prev')
stepHighlighter.highlightSteps(stepIds[])
stepHighlighter.clearHighlights()

// TheoremPopup
theoremPopup.showPopup(target, theoremId)
theoremPopup.scheduleHide()

// DependencyGraph
dependencyGraph.render(proofData, graph)
dependencyGraph.clear()

// LaTeXExporter
latexExporter.export(proof, metadata)
latexExporter.downloadAsFile(proof, filename)

// ProofSearch
proofSearch.findUsages(theoremId)     // 返回 usage[]
proofSearch.searchProofs(query)       // 返回 result[]

// CompletenessIndicator
completenessIndicator.render(proof)   // 显示完整度

// ProofFlowAnimator
flowAnimator.render(proof)
flowAnimator.destroy()
