Formula Nebula - Settings Demo

设置系统演示

这是 Formula Nebula 个性化设置系统的完整演示。点击上方按钮打开设置面板。

功能特性

  • 完整的设置面板 UI
  • 本地存储支持
  • 自动同步到服务器
  • 主题切换（浅色/深色/自动）
  • 多语言支持
  • 通知设置
  • 隐私与安全设置
  • 无障碍选项
  • 设置导出/导入
  • 快捷键管理

使用代码

import { initializeSettings } from './src/settings/index.js';

// 初始化设置管理器
const settingsManager = initializeSettings({
  container: document.getElementById('settings-panel'),
  userId: 'demo-user',
  autoSync: true,
  onSave: (settings) => {
    console.log('Settings saved:', settings);
  }
});

// 打开设置面板
document.getElementById('open-settings-btn').addEventListener('click', () => {
  settingsManager.open();
});

// 关闭设置面板（自动通过 X 按钮）
