🚀 Formula Nebula Billing Dashboard

Freemium SaaS Tier Management System

📚 How to Use This Demo

  • Create Collection: Simulates creating a new collection (limited to 5 on Free tier)
  • Upload File: Simulates uploading a 50MB file (limited to 10MB per file on Free tier)
  • API Calls: Simulates 10 API calls (limited to 100/day on Free tier)
  • Upgrade: Click upgrade buttons on tier cards to test the upgrade flow
  • Reset: Clears all usage and resets to Free tier

💻 Integration Code

To integrate this in your application:

import { initBillingDashboard } from './src/billing/dashboard.js';

const container = document.getElementById('billing-dashboard');
initBillingDashboard(userId, container, {
  autoRefresh: true,
  refreshInterval: 30000
});
