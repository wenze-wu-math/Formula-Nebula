┌─ 🆘 常见问题 ─────────────────────────────────────────────────┐

Q: 卡在加载？
A: LaTeX 排版需要 3~6 秒。看进度条。等等再说。

Q: 字太小？
A: 单击公式会自动推近。或打开"引力模式"让公式静止。

Q: 端口被占用？
A: Vite 自动换下一个端口。控制台会显示实际地址。

Q: 想用其它端口？
A: set NEBULA_PORT=6000 && npm run dev

Q: 生产部署？
A: npm run build  →  生成 dist/  →  部署到任何 static hosting
