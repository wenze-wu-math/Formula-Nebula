# Cloudflare Workers Quick Start

## 🚀 Fastest Deployment (5 minutes)

### 1. Install & Login
```bash
npm install -g wrangler
wrangler login
```

### 2. Create KV Namespaces
```bash
wrangler kv:namespace create "RATE_LIMIT_KV"
wrangler kv:namespace create "ANALYTICS_KV"
wrangler kv:namespace create "RATE_LIMIT_KV" --preview
wrangler kv:namespace create "ANALYTICS_KV" --preview
```

### 3. Update wrangler.toml
Copy the namespace IDs from step 2 output into `wrangler.toml`:

```toml
[[kv_namespaces]]
binding = "RATE_LIMIT_KV"
id = "PASTE_YOUR_ID_HERE"
preview_id = "PASTE_YOUR_PREVIEW_ID_HERE"

[[kv_namespaces]]
binding = "ANALYTICS_KV"
id = "PASTE_YOUR_ID_HERE"
preview_id = "PASTE_YOUR_PREVIEW_ID_HERE"
```

### 4. Deploy
```bash
wrangler deploy
```

### 5. Test
```bash
curl https://formula-nebula-edge.YOUR_SUBDOMAIN.workers.dev/__worker/health
```

## 📊 View Analytics
```bash
curl "https://formula-nebula-edge.YOUR_SUBDOMAIN.workers.dev/__worker/analytics?range=hour"
```

## 🔧 Configuration

Edit `wrangler.toml` to adjust:

```toml
[vars]
MAX_REQUESTS_PER_MINUTE = "100"    # Rate limit
CACHE_TTL_SECONDS = "3600"          # Cache duration
ENABLE_ANALYTICS = "true"           # Toggle analytics
ENABLE_GEO_ROUTING = "true"         # Toggle geo routing
ENABLE_DDOS_PROTECTION = "true"     # Toggle DDoS protection
```

## 📝 Custom Domain (Optional)

1. Add domain to Cloudflare
2. Update `wrangler.toml`:
   ```toml
   workers_dev = false
   route = "your-domain.com/*"
   zone_id = "YOUR_ZONE_ID"
   ```
3. Redeploy: `wrangler deploy`
