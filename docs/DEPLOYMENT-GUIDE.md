## 常见问题

### Q1: 新首页会不会破坏 SEO？
**A:** 不会。新首页保留了所有的 meta 标签和 schema.org 结构化数据。甚至改进了：
- 更清晰的 h1（改为"用星云探索数学的灵魂"）
- 更好的关键词优化
- 更快的加载速度

### Q2: 动画会不会减慢页面加载？
**A:** 不会。所有动画都是 CSS，不需要 JavaScript：
- 无额外 JS 下载
- CSS 已内联（无网络请求）
- 动画只在浏览器空闲时执行

### Q3: 旧浏览器会怎样？
**A:** 完美降级：
- CSS 动画不支持 → 显示静态内容
- 布局继续正常工作
- 所有交互仍然可用

### Q4: 怎么测试移动设备？
**A:** 
```bash
# 使用 Chrome DevTools
1. 打开 F12
2. 点击设备工具栏图标
3. 选择 iPhone 12 / iPad 等

# 或在真机测试
1. 连接到同一 WiFi
2. 访问 http://<your-ip>:8000
```

### Q5: 动画在低端设备上怎样？
**A:** 已优化：
- 使用 `will-change` 提示浏览器
- 避免复杂的合成动画
- 提供 `prefers-reduced-motion` 支持

```css
@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; }
}
```

## 常见故障排查

### 问题 1：动画不显示
```
症状：看不到星云旋转动画
解决：
1. 检查浏览器是否支持 @keyframes
   → Chrome 43+, Firefox 16+, Safari 9+
2. 检查是否启用了"减少运动"
   → macOS: 系统偏好设置 > 辅助功能 > 显示 > 减少运动
   → Windows: 设置 > 轻松使用 > 显示 > 显示动画
3. 检查控制台是否有错误
   → 按 F12 查看 Console 标签
```

### 问题 2：页面加载缓慢
```
症状：首页需要 > 2 秒 加载
解决：
1. 检查 CSS 是否被正确内联
2. 检查网络连接速度
3. 使用 Chrome DevTools Network 标签分析
```

### 问题 3：按钮链接不工作
```
症状：点击"进入体验"没反应
解决：
1. 检查 /index.html 是否存在
2. 检查浏览器控制台是否有 JavaScript 错误
3. 检查是否在正确的目录结构中
```
