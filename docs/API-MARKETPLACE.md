# API Marketplace Architecture

## Overview

The Formula Nebula API Marketplace enables third-party developers to publish, discover, and consume mathematical APIs with built-in rate limiting, analytics, revenue sharing, and auto-generated documentation.

## Architecture Components

### 1. Core Modules

```
src/api-marketplace/
├── marketplace.js         # Main marketplace orchestrator
├── publisher.js          # API publishing and versioning
├── consumer.js           # API consumption and discovery
├── registry.js           # API registry and metadata
├── documentation.js      # Auto-generated API docs
├── analytics.js          # Usage tracking and analytics
├── revenue.js           # Revenue tracking and sharing
└── examples/            # Example API implementations
    ├── formula-api.js

src/api-keys/
├── management.js        # API key lifecycle management
├── rate-limiter.js     # Rate limiting engine
├── quota-tracker.js    # Usage quota tracking
└── security.js         # Key encryption and validation
```

### 2. Data Models

#### API Definition
```javascript
{
  apiId: string,              // Unique API identifier
  name: string,               // Display name
  version: string,            // Semantic version
  publisher: {
    userId: string,
    displayName: string,
    reputation: number
  },
  description: string,
  category: string[],         // Tags: math, algebra, geometry
  endpoints: Endpoint[],
  pricing: {
    model: 'free' | 'tiered' | 'usage',
    tiers: PricingTier[]
  },
  rateLimits: {
    requestsPerMinute: number,
    requestsPerDay: number,
    burstLimit: number
  },
  documentation: {
    autoGenerated: boolean,
    readme: string,
    examples: Example[]
  },
  metrics: {
    totalCalls: number,
    activeConsumers: number,
    avgResponseTime: number,
    errorRate: number
  },
  revenueShare: {
    publisherShare: number,    // Percentage (0-100)
    platformFee: number
  },
  status: 'draft' | 'published' | 'deprecated',
  createdAt: Date,
  updatedAt: Date
}
```

#### API Key
```javascript
{
  keyId: string,
  key: string,                // Hashed
  consumerId: string,
  apiId: string,
  name: string,               // User-defined key name
  permissions: string[],      // Endpoint access list
  quotas: {
    requestsPerMinute: number,
    requestsPerDay: number,
    requestsPerMonth: number,
    remaining: {
      minute: number,
      day: number,
      month: number
    }
  },
  usage: {
    totalRequests: number,
    lastUsed: Date,
    bandwidth: number          // Bytes
  },
  status: 'active' | 'suspended' | 'revoked',
  expiresAt: Date,
  createdAt: Date
}
```

#### Usage Record
```javascript
{
  recordId: string,
  apiId: string,
  apiKeyId: string,
  consumerId: string,
  endpoint: string,
  method: string,
  statusCode: number,
  responseTime: number,       // Milliseconds
  bytesTransferred: number,
  timestamp: Date,
  metadata: {
    userAgent: string,
    ipAddress: string,
    errorMessage?: string
  }
}
```

#### Revenue Record
```javascript
{
  recordId: string,
  apiId: string,
  publisherId: string,
  period: string,             // YYYY-MM
  metrics: {
    totalCalls: number,
    uniqueConsumers: number,
    revenue: number,
    cost: number
  },
  distribution: {
    publisherAmount: number,
    platformAmount: number,
    paidOut: boolean,
    paidAt?: Date

```

### 3. API Publishing Workflow

```
1. Developer creates API definition
   ↓
2. Code implementation with standard interface
   ↓
3. Documentation auto-generation from JSDoc/OpenAPI
   ↓
4. Testing and validation
   ↓
5. Pricing and rate limit configuration
   ↓
6. Submit for review (optional)
   ↓
7. Publish to marketplace
   ↓
8. Monitor usage and analytics
```

### 4. API Consumption Workflow

```
1. Discover APIs in marketplace
   ↓
2. Review documentation and pricing
   ↓
3. Subscribe to API
   ↓
4. Generate API key
   ↓
5. Integrate API into application
   ↓
6. Monitor usage and quotas
   ↓
7. Upgrade tier if needed
```

### 5. Rate Limiting Strategy

#### Token Bucket Algorithm
- Requests consume tokens from bucket
- Bucket refills at configured rate
- Burst capacity for temporary spikes
- Per-key and per-endpoint limits

#### Limit Tiers

{

### 7. Revenue Sharing Model

#### Calculation
```javascript
Monthly Revenue = (API Calls × Cost per Call) + Subscription Fees
Publisher Share = Monthly Revenue × Publisher Percentage
Platform Fee = Monthly Revenue × Platform Percentage
```

#### Default Split
- Publisher: 70%
- Platform: 30%

#### Volume Bonuses
- 10K+ calls/month: +5% to publisher
- 100K+ calls/month: +10% to publisher
- 1M+ calls/month: +15% to publisher

### 10. Example APIs

#### Formula Evaluation API
```
POST /api/v1/formula/evaluate
- Evaluate mathematical expressions
- Returns: numeric result, symbolic form, latex

GET /api/v1/formula/parse
- Parse formula into AST
- Returns: syntax tree, tokens

GET /api/v1/formula/simplify
- Simplify algebraic expressions
- Returns: simplified form, steps
```

#### Proof Verification API
```
POST /api/v1/proof/verify
- Verify mathematical proof validity
- Returns: valid/invalid, errors, suggestions

GET /api/v1/proof/suggest
- Get proof suggestions for theorem
- Returns: proof strategies, similar theorems

POST /api/v1/proof/format
- Format proof in standard notation
- Returns: formatted proof, latex
```

#### Graph Query API
```
GET /api/v1/graph/search
- Search knowledge graph
- Returns: matching nodes, relationships

GET /api/v1/graph/path
- Find shortest path between concepts
- Returns: path, distance, intermediate nodes

GET /api/v1/graph/neighbors
- Get neighboring concepts
- Returns: connected nodes, relationship types
```

## Integration Examples

### Publishing an API
```javascript
import { APIMarketplace } from './api-marketplace/marketplace.js';

const api = await marketplace.publishAPI({
  name: 'Formula Evaluator',
  version: '1.0.0',
  endpoints: [
    {
      path: '/evaluate',
      method: 'POST',
      handler: evaluateFormula,
      rateLimit: { requestsPerMinute: 100 }
    }
  ],
  pricing: {
    model: 'tiered',
    tiers: [
      { name: 'free', limit: 1000, price: 0 },
      { name: 'pro', limit: 100000, price: 29 }
    ]
  }
});
```

### Consuming an API
```javascript
import { APIConsumer } from './api-marketplace/consumer.js';

const consumer = new APIConsumer({ apiKey: 'your-api-key' });

const result = await consumer.call('formula-evaluator', {
  endpoint: '/evaluate',
  method: 'POST',
  data: { expression: 'x^2 + 2x + 1' }
});
```
