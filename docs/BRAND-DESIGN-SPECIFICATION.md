# 公式诗云 (Formula Nebula) - 品牌设计规范

**最后更新**: 2026-11-03

---

## I. 品牌核心价值

公式诗云是一个**代数几何知识图谱的三维星云可视化系统**，致力于让复杂的数学知识通过空间与光影的语言变得可感知、可交互。

核心理念：
- **宇宙即知识** - 将数学定理、猜想映射为星系中的星体
- **光流与结构** - 通过发光、大小、距离表达重要度与关联
- **浮游与自转** - 动态的、三维的、沉浸式的知识体验

## II. Logo 设计（多个变体）

### 2.1 主 Logo - "星核"

**设计理念**: 
- 中心一个发光的球体（知识核心）
- 围绕四条对数螺旋臂（四大知识族群）
- 上方一个虚点阵球（猜想星团）
- 整体呈"旋涡星系"形态

**构成要素**:
1. **中心核球** - 代表最核心的定理与基础知识
   - 填充色: 主品牌色 (见 3.1)
   - 辉光效果: 外层柔光晕
   
2. **四条旋臂**
   - 角度分布: 90° 均匀分布
   - 缠绕系数: 5.2 弧度螺旋
   - 线宽递减: 从核心向外逐渐变细
   
3. **猜想球** (位置: +x 方向, 距离核心)
   - 透明网格球面
   - 半径相对核盘 28.6%
   - 表示未定论知识

**比例关系**:
```
总尺寸: 1:1 正方形包围盒
核球直径: 总尺寸的 20%
旋臂外半径: 总尺寸的 42%
旋臂厚度: 核心 3.2%, 边缘 1.4%
星团球半径: 26% 的总尺寸
水平偏移: +27%
深度偏移: -14%
```

**可用场景**:
- 应用启动画面 (256px)
- 文档头部 (96px)
- 社交媒体头像 (400px)
- 打印品 (印刷尺寸)

### 3.6 辉光与发光

**发光点（Glow）配置**:
```

```

```

强度: 1.8
半径: 0.8
```

## IV. 字体选择

### 4.1 科学领域标准

为确保**严谨性**与**国际化**，选用业界标准：

#### 英文字体

**标题 / 品牌**: Inter (600, 700 weight)
```
特点: 无衬线, 清晰, 1.0 字宽数值零 (0与O可分)
用途: Logo, 应用标题, 弹出框标题
```

**正文**: Fira Sans Regular (400, 500)
```
特点: 开源, 高对比度, 易于屏幕阅读
用途: 文档正文, UI 标签, 数值
```

#### 中文字体

**标题**: LXGW WenKai (思源黑体 Bold 字重对标)
```
特点: 开源, 美观, 支持科技感排版
用途: 品牌标语, 中文标题
```

**正文**: Noto Sans CJK SC (Regular 400)
```
特点: Google Noto 系列, 高度支持, 中英混排无缝
用途: 文档正文, 界面文字
```

#### 数学排版

**LaTeX 公式**: MathJax (默认配置)
- **渲染引擎**: 本项目已集成 `mathjax-full`
- **字体栈**: STIX Two, Cambria Math
- **品质**: 基于传统活字排版

## V. 品牌指南

### 5.1 Logo 使用规范

#### 5.1.1 最小尺寸

- **屏幕显示**: 不小于 64px × 64px
- **打印品**: 不小于 2cm × 2cm
- 低于最小尺寸时，使用**简化版 Logo**（仅星盘）

#### 5.1.2 安全区域（清空区域）

Logo 周围最少留空：Logo 高度的 **0.5 倍**

```
┌─────────────────────┐
│  [0.5H] 空白区 [0.5H] │
│  [0.5W]  LOGO [0.5W] │
│  [0.5H] 空白区 [0.5H] │
└─────────────────────┘
```

#### 5.1.3 禁用事项

❌ 旋转超过 360°（会破坏螺旋感）
❌ 改变宽高比例
❌ 改变颜色（除非特别说明）
❌ 添加阴影或 3D 效果
❌ 与其他图形重叠
❌ 拉伸或压扁

---

### 5.2 色彩使用规范

#### 5.2.1 主色使用场景

**光彩蓝 `#0D47A1`**:
- 核心按钮 (Primary CTA)
- 链接文字
- 活跃状态指示
- Logo 核心
- 数据可视化主色

**知识橙 `#FF8F6B`**:
- 警告/重要提示
- 次级按钮
- 未解决状态
- 强调突出

#### 5.2.2 对比度要求

WCAG AA 最低标准：
- **文本与背景**: 4.5:1 (小文本) / 3:1 (大文本)
- **UI 组件**: 3:1
- **图表元素**: 3:1

当前配置检验：
```
光彩蓝 (#0D47A1) vs 深空灰 (#1A1E2E): 6.8:1 ✓
知识橙 (#FF8F6B) vs 深空灰 (#1A1E2E): 4.2:1 ✓
```

#### 5.2.3 深色 / 浅色模式

当前设计**原生适配深色模式**：
- 背景: 深空灰系
- 文本: 浅灰
- 高亮: 高饱和色

**浅色模式** (若需要):
- 反转所有 RGB: `255 - R, 255 - G, 255 - B`
- 调整对比度保证可读性

## VI. 品牌一致性检查清单

实施品牌设计时，逐项检验：

- [ ] Logo 比例与安全区域符合规范
- [ ] 色彩采样值精确到 ±2 (RGB) / ±0.01 (OKLab)
- [ ] 字体文件已正确加载 (验证 font-family 生效)
- [ ] 文本对比度通过 WCAG AA 检验
- [ ] 间距遵循 8px 网格或已记录偏差理由
- [ ] 公式渲染清晰，无锯齿或模糊
- [ ] 深色模式亮度满足要求
- [ ] 打印输出测试无漂移
- [ ] 所有使用案例已备档案
