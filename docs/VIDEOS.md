## 制作指南

### 录制规格

| 参数 | 推荐值 |
|---|---|
| **分辨率** | 1920×1080 (16:9) 或 3840×2160 (4K) |
| **帧率** | 60 fps（流畅的三维旋转） |
| **比特率** | H.264: 8-12 Mbps (1080p), 35-45 Mbps (4K) |
| **音频** | AAC 192 kbps, 48 kHz, 立体声 |
| **格式** | MP4 (H.264 + AAC) |

### 录制工具

| 工具 | 适用场景 | 特点 |
|---|---|---|
| **OBS Studio** | 全场景（免费开源） | 灵活、自定义布局、实时标注 |
| **Camtasia** | 教程向（商业软件） | 内置动画、标注、后期编辑 |
| **ScreenFlow** (macOS) | 专业制作 | 高质量录制、强大后期 |
| **Loom** | 快速录制分享 | 在线录制、即时分享 |

### 录制前准备清单

```bash
# ① 确保本地开发环境运行正常
npm install
npm run build
npm run preview    # 使用生产构建，确保性能

# ② 准备演示数据
# - 清除浏览器缓存（首次加载真实体验）
# - 准备好要演示的搜索关键词
# - 提前找好要点击的节点（避免录制时找不到）

# ③ 浏览器设置
# - 隐藏书签栏（Ctrl+Shift+B）
# - 使用无痕窗口（避免扩展干扰）
# - F11 全屏模式（录制时）

# ④ 性能优化
# - 关闭不必要的后台程序
# - 确保 GPU 加速启用
# - 检查 FPS（开发者工具 → Performance Monitor）
```

### 音频录制建议

| 要素 | 建议 |
|---|---|
| **麦克风** | USB 电容麦（Blue Yeti / Audio-Technica AT2020） |
| **环境** | 安静房间，关闭空调/风扇噪声 |
| **音量** | 峰值 -6dB，平均 -18dB（不失真） |
| **语速** | 中速（不要太快），清晰吐字 |
| **停顿** | 操作时留 1-2 秒停顿（方便剪辑） |
| **后期** | 降噪、均衡器、压缩器（Audacity 免费） |

### 屏幕录制要点

1. **分辨率与缩放**
   - 系统缩放 100%（避免模糊）
   - 浏览器窗口 1920×1080 或全屏
   - 字体大小检查（至少 16px 可读）

2. **鼠标指针**
   - 启用指针高亮（OBS: "Show mouse cursor" + Highlight）
   - 鼠标移动平稳（不要抖动）
   - 点击时停顿 0.5 秒（让观众看清）

3. **录制流程**
   - 录前预演 2-3 遍（熟悉流程）
   - 录制时对照脚本（保持节奏）
   - 每段独立录制（方便后期拼接）
   - 出错立即重录该段（不要硬接）

4. **后期制作**
   - 片头 5 秒：项目 Logo + 视频标题
   - 片尾 5 秒：官网链接 + GitHub
   - 字幕：中英双语（覆盖 80%+ 关键信息）
   - 标注：箭头/圈圈/放大（强调关键操作）
   - 转场：淡入淡出 0.5 秒（不要花哨特效）

| 部分 | 内容 |

| **演示素材** | 需要准备的示例数据 |
| **常见问题** | 可能遇到的问题及解答 |

### 字幕文件格式

推荐使用 **SRT** 格式（兼容性最好）：

```srt
1
00:00:00,000 --> 00:00:05,000
欢迎来到公式诗云
Welcome to Formula Nebula

2
00:00:05,500 --> 00:00:10,000
这是一个代数几何知识图谱的三维可视化
A 3D visualization of algebraic geometry knowledge graph
```

生成工具：
- **Subtitle Edit**（免费，Windows/Linux）
- **Aegisub**（开源，跨平台）
- **YouTube 自动字幕** + 人工校对

### 测试观众

发布前请至少 **3 位不同背景** 的人试看：

1. **目标用户**（数学/研究背景） → 检查专业性
2. **普通用户**（无背景知识） → 检查可理解性
3. **技术用户**（开发者） → 检查 API 教程准确性

收集反馈：
- 哪些地方听不懂/看不清
- 节奏是否合适（太快/太慢）
- 是否有遗漏的关键功能
