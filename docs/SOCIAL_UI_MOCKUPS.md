## Usage Examples

### Opening Social Hub

```javascript
import { showSocialHub } from './socialHub.js'

// From a button click
document.getElementById('social-btn').onclick = showSocialHub

// From keyboard shortcut
document.addEventListener('keydown', (e) => {
  if (e.ctrlKey && e.key === 's') {
    showSocialHub()
  }
})
```

### Tracking User Actions

```javascript
import { 
  trackProofView, 
  trackProofUnderstood,
  trackTheoremProved 
} from './social.js'

// When opening a proof
function openProof(proofId) {
  // ... display proof logic
  trackProofView(proofId, proof.title)
}

// When user marks as understood
function markAsUnderstood(proofId) {
  // ... save understanding
  trackProofUnderstood(proofId, proof.title)
  showToast('🎉 +50 XP!')
}

// When formal proof verified
function onProofVerified(theoremId) {
  // ... verification logic
  trackTheoremProved(theoremId, theorem.title)
  showToast('🏆 +200 XP!')
}
```

### Custom Badge Creation

```javascript
import { BADGE_DEFINITIONS } from './social.js'

// Add custom badge
BADGE_DEFINITIONS.night_owl = {
  badgeId: 'night_owl',
  name: 'Night Owl',
  description: 'Study after midnight 10 times',
  icon: '🦉',
  tier: 'silver',
  criteria: { nightStudySessions: 10 },
  rarity: 0.15,
}
```

## Implementation Notes

1. **Social Hub Opens as Modal** - Overlays main view
2. **localStorage Persistence** - All data saved locally
3. **No Server Required** - Fully client-side for v1
4. **Privacy First** - Users control visibility
5. **Performance Optimized** - Lazy loading of tabs
6. **Mobile Responsive** - Adapts to screen size
7. **Extensible Design** - Easy to add new features
