## 四大分析维度

### 1️⃣ 用户行为跟踪 (User Behavior Tracking)
**看什么**: 用户如何与系统交互
- 📊 哪个可视化最受欢迎？
- 👥 用户参与度分布如何？
- ⏱️ 平均会话时长是多少？
- ✅ 任务完成率是否达标？

**关键指标**:
- 总交互数: 越高越活跃
- 平均会话时长: 越长越吸引
- 任务完成率: 越高越有效

---

### 2️⃣ 转化漏斗 (Conversion Funnel)
**看什么**: 用户从开始到满意的转化路径
- 🎯 初始化 → 已开始 (用户是否启动?)
- 📈 已开始 → 已参与 (用户是否参与?)
- ✨ 已参与 → 已完成 (用户是否坚持?)
- 💯 已完成 → 满意 (用户是否满意?)

**优化目标**:
- 高流失率 > 30% 的阶段需要改进
- 对标行业平均 50-70% 留存率

---

### 3️⃣ 特征分析 (Feature Analysis)
**看什么**: 四种可视化（Atlas, Map, Manuscript, Nebula）的性能对比
- 🏆 哪个可视化表现最好？
- 📉 哪个需要改进？
- 💪 综合评分排名
- 🎮 用户交互类型分布

**性能评级**:
| 综合评分 | 等级 |
|---------|------|
| 4.0-5.0 | ⭐⭐⭐⭐⭐ 优秀 |
| 3.0-4.0 | ⭐⭐⭐⭐ 良好 |
| 2.0-3.0 | ⭐⭐⭐ 中等 |
| <2.0 | ⭐⭐ 需改进 |

---

### 4️⃣ 保留率分析 (Retention Analysis)
**看什么**: 用户如何随时间流失或忠诚
- 📅 日1留存率: 初始参与力 (应 > 90%)
- 📊 日7留存率: 短期参与度 (应 > 60%)
- 🔄 日30留存率: 长期忠诚度 (应 > 40%)
- ⚠️ 风险用户: 需要干预的用户
- 💎 忠实用户: 核心用户群

**健康指标**:
| 保留率 | 健康度 | 行动 |
|-------|--------|------|
| > 70% | ✓ 优 | 继续维持 |
| 50-70% | ⚠️ 中 | 重点关注 |
| < 50% | ❌ 差 | 紧急改进 |

## 实际应用场景

### 场景1: 快速了解产品健康度
```
→ 打开仪表板
→ 看顶部4个KPI卡片
→ 判断: 用户量/完成率/性能/留存
```

### 场景2: 诊断用户流失问题
```
→ 查看转化漏斗
→ 找到流失率最高的阶段
→ 分析该阶段的UX/内容问题
→ 制定改进方案
```

### 场景3: 对比功能性能
```
→ 查看特征分析表格
→ 比较4个可视化的综合评分
→ 识别表现不佳的功能
→ 优化或重设计
```

### 场景4: 评估用户忠诚度
```
→ 查看保留率分析
→ 对比日1/日7/日30数据
→ 评估用户粘性
→ 制定留存策略
```

## 数据解读技巧

### 快速诊断清单
- [ ] 总用户数是否达到目标?
- [ ] 任务完成率 > 70%?
- [ ] 最常用功能是否是最好的?
- [ ] 转化漏斗有明显断层吗?
- [ ] 日30留存率 > 40%?
- [ ] 风险用户 < 20%?

### 常见问题

**Q: 为什么完成率低?**
- A: 检查特征分析 - 是否某个可视化太难?

**Q: 用户在哪里流失?**
- A: 看转化漏斗 - 比较各阶段的流失率

**Q: 哪个功能最有价值?**
- A: 看特征分析中的综合评分排名

**Q: 如何提高留存?**
- A: 分析忠实用户的行为模式，推荐高参与度可视化

## 进阶使用

### 自定义输出
```bash
node tools/analytics-dashboard.mjs --output my-report.html
```

### 集成到工作流
```bash
# 定期生成仪表板
node tools/analytics-dashboard.mjs

# 保存特定时间点的快照
cp data/analytics/analytics_dashboard_*.html backups/snapshot_$(date +%Y%m%d).html
```

仪表板可与以下工具配合:
- `tools/analyze-user-study.mjs` - 详细统计分析
- `tools/user-study-runner.mjs` - 数据收集
